# Dotfiles Bootstrapper

Idempotent, zero-dependency setup for macOS and Linux.

## Quick Start
```zsh
/bin/zsh -c "$(curl -fsSL [https://raw.githubusercontent.com/janhrabcak/dotfiles/main/bootstrap.sh](https://raw.githubusercontent.com/your-username/dotfiles/main/bootstrap.sh))" -- --remote
```
